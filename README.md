
# Meu Portfólio Acadêmico

## Sobre o projeto

Este projeto consiste no desenvolvimento de um site pessoal em formato de portfólio acadêmico, criado para apresentar minha trajetória estudantil, atividades, projetos e habilidades.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Funcionalidades

- Navegação entre as seções do portfólio.
- Menu adaptado para dispositivos móveis.
- Animações de entrada durante a rolagem.
- Apresentação de projetos e atividades acadêmicas.
- Seções para habilidades e contato.

## Estrutura do projeto

- `index.html`: estrutura e conteúdo do site.
- `style.css`: estilos, layout e responsividade.
- `script.js`: interatividade e animações.
- `README.md`: documentação do projeto.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
